# ⚡ START HERE - One-Click Installation

**Welcome to SamFWTool! Get started in 30 seconds.**

---

## 🚀 Quick Start (Choose Your OS)

### 🐧 Linux / 🍎 macOS

Open terminal in this directory and run:

```bash
./RUN.sh
```

**That's it!** The script will install everything and show you a menu.

---

### 🪟 Windows

Double-click:

```
RUN.bat
```

Or open Command Prompt in this directory and run:

```cmd
RUN.bat
```

**That's it!** The script will install everything and show you a menu.

---

## ✅ What Happens Next

1. **Auto-Install** - Checks Python, installs dependencies
2. **Auto-Configure** - Sets up SamFWTool
3. **Interactive Menu** - Shows you options:
   - Run CLI (command line interface)
   - Run GUI (graphical interface)
   - Show help
   - Compare with other tools

### "Permission denied" (Linux/macOS)
```bash
chmod +x RUN.sh INSTALL.sh
```
